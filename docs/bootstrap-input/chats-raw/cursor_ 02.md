## 🔧 ما كانت المشكلة؟

كان هناك خطأ في **interface Schedule** في صفحة CMS:
- كان يستخدم: `department: { name: string }`
- لكن قاعدة البيانات تحتوي على: `nameAr` و `nameEn`

## ✅ ما تم إصلاحه:

1. **تحديث Interface** لتطابق قاعدة البيانات:
```typescript
interface Department {
  id: string;
  nameAr: string;
  nameEn: string;
}
```

2. **تحديث عرض اسم القسم**:
   - من: `schedule.department?.name`
   - إلى: `schedule.department?.nameAr`

3. **إضافة جلب الأقسام من API**:
   - إضافة state للأقسام
   - إضافة دالة `fetchDepartments()`
   - تحديث قائمة الأقسام لتكون ديناميكية

4. **قائمة الأقسام في نموذج الإضافة**:
   - تم استبدال القيم الثابتة
   - بقائمة ديناميكية من قاعدة البيانات
