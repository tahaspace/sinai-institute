- أضفت Tab جديد "اختر تخصصك" 🎓
- واجهة إدارة شاملة تتضمن:
  - ✅ عرض جميع التخصصات الحالية
  - ✅ إضافة تخصصات جديدة

  - ✅ إخفاء/إظهار التخصصات (👁️)
