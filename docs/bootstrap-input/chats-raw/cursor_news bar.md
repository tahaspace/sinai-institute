## الميزات الجديدة:

### 1. **زر تعديل لكل خبر** 📝
- يظهر زر تعديل بجانب زر الحذف لكل خبر

### 2. **وضع التعديل المرئي** 🎨
- عند الضغط على تعديل، يتم تحديد الخبر بإطار أزرق
- يظهر شارة "قيد التعديل" على الخبر المحدد

### 3. **وظائف التعديل** ⚙️
- عند الضغط على تعديل، يتم ملء النموذج ببيانات الخبر الحالي
- يظهر زر "حفظ التعديلات" بدلاً من "إضافة الخبر"
- يظهر زر "إلغاء التعديل" لإلغاء عملية التعديل

### 4. **تأكيد الحذف** ⚠️
- يطلب تأكيد قبل حذف أي خبر

### 5. **رسائل واضحة** 💬
- رسائل toast توضح كل عملية (تعديل، حفظ، إلغاء، حذف)
